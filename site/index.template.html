WireGuard Obfuscator

Custom App для нативного WireGuard-клиента RouterOS.

Подключение каталога

/app/settings set app-store-urls="__CATALOG_URL__"

После этого откройте WebFig → Apps, установите wg-obfuscator-client и задайте переменные из конфигурации WireGuard Obfuscator Easy.

Параметры App

  • WG_OBF_TARGET — публичный адрес и UDP-порт сервера.
  • WG_OBF_KEY — ключ из клиентской конфигурации.
  • WG_OBF_MASKING — рекомендуется STUN.
  • WG_OBF_SOURCE_PORT — локальный порт, по умолчанию 13255.

Интеграция с RouterOS

Скачайте install.template.rsc, вставьте WireGuard private key, server public key и внешний IPv4 сервера, затем импортируйте файл.

/import install.template.rsc

Диагностика: diagnose.rsc. Удаление RouterOS-настроек: uninstall.rsc.

Container package и device mode необходимо включить заранее. Файл установки содержит WireGuard private key — удалите его с роутера после импорта.
